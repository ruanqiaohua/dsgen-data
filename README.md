# dsgen-data

[dsgen.cn](https://dsgen.cn) 机型对比工具的公共机型库提交入口。

## 提交一台机器

打开 [新建 Issue](../../issues/new?template=add-device.yml)，填清楚：

- 机型名称（带容量，例如 `RTX 5080 · 16GB`）
- 类型（独显 / 苹果统一内存 / 其他）
- 内存或显存容量（GB）
- **内存带宽（GB/s）** —— 这个数决定本地推理速度，最重要
- 参考价格、规格来源链接（可选）

审核通过后会合并进 `devices.js`，所有人生效。

## 只收能查到规格的机器

带宽查不到就先别提交。这个站的价值在于数据可信，宁可少也不要错。
